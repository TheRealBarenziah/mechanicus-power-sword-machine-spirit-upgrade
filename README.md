# Mechanicus Power Sword: Machine Spirit Upgrade

- Numerical charge counter for the Mechanicus Power Sword and Arc Maul (optionally the two-handed force sword too): a `4/6` counter in place of the stock pips, and a bar for the special's wind-up stages or the recharge.  
- Stock gauge can be hidden, kept, recoloured, or moved next to the reticle.
- Move the elements with [Custom HUD](https://www.nexusmods.com/warhammer40kdarktide/mods/331) or the built-in offsets.

## Installation

Extract into your Darktide `mods` folder (`...\steamapps\common\Warhammer 40,000 DARKTIDE\mods`) and add `machine_spirit_upgrade` to `mods\mod_load_order.txt` - or just use a [mod manager](https://www.nexusmods.com/warhammer40kdarktide/mods/139).

## Requirements

- [Darktide Mod Loader](https://www.nexusmods.com/warhammer40kdarktide/mods/19)
- [Darktide Mod Framework](https://www.nexusmods.com/warhammer40kdarktide/mods/8)
